# 🚀 Page Plus - Website Audit API

A production-ready REST API built with **Node.js, Express, TypeScript** that audits websites and returns useful SEO and performance information.

---

## ✨ Features

- Website Audit API
- URL Validation (Zod)
- Response Caching
- Rate Limiting
- Global Error Handling
- Request Logging (Pino)
- Swagger Documentation
- Docker Support
- Unit & Integration Testing
- TypeScript

---

## 🛠 Tech Stack

- Node.js
- Express.js
- TypeScript
- Axios
- Cheerio
- Zod
- Swagger UI
- Docker
- Jest
- Supertest
- Pino Logger
- Node Cache
